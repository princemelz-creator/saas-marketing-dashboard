# MarketoSaas.

A professional wed presence for **MarketoSaas** where the market is beautifully designed.


## Project Overview


This project is a website designed to showcase  the various campings of marketing branch.


## Project Structure
- `index.html` : this is the main page where you get to see the various campings by various marketing channels.
- Our styling is done by tailwindcss

## Getting started
1. clone this repository on your machine.

```bash
git clone https://github.com/princemelz-creator/saas-marketing-dashboard.git

cd saas-marketing-dashboard.git
```
2. Open `index.html` in any modern browser to view the web page.
3. No build tools or dependencies required for this version.
